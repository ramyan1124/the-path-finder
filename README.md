CAREER GUIDANCE WEB APPLICATION – “THE PATH FINDER”

Live Demo

1. INTRODUCTION

Career selection is one of the most critical decisions in a student’s life. Many students face confusion after completing school or graduation due to a lack of proper guidance, awareness of career options, and understanding of required skills. Traditional career guidance methods are often limited, generic, and not personalized.

The Path Finder is a web-based career guidance application designed to help students identify the best educational and career path based on their academic background, interests, and goals. The platform provides structured career recommendations, step-by-step roadmaps, and region-specific (Tamil Nadu) education pathways using a modern, user-friendly interface.

2. OBJECTIVES OF THE PROJECT

The main objectives of this project are:

To guide students in choosing the right career path after 10th, 12th, Diploma, UG, PG, or Career Break

To provide clear and explainable career roadmaps

To reduce confusion in career decision-making

To present Tamil Nadu–specific education and career recommendations

To design a responsive and professional web application

To demonstrate frontend development and UI/UX design skills

3. PROBLEM STATEMENT

Many students lack access to structured and personalized career guidance. Existing solutions often provide generic suggestions without explaining eligibility, steps, or alternatives. There is a need for a system that:

Analyzes a student’s education and interests

Provides clear career paths and alternatives

Is easy to understand and visually informative

Works without complex backend infrastructure for academic use

4. PROPOSED SOLUTION

The proposed solution is a frontend-based career guidance web application that:

Collects user input such as education level, stream, and interest

Matches the input with a pre-collected career dataset

Displays a recommended career with a step-by-step roadmap

Suggests alternate career options

Provides region-specific (Tamil Nadu) education pathways

Uses modern UI components for better user experience

5. SYSTEM ARCHITECTURE

The system follows a simple and efficient architecture:

User Interface (Frontend)

HTML, CSS, Bootstrap for layout and styling

JavaScript for interaction and logic

Career Data Source

JSON file containing career paths, eligibility, and roadmaps

Logic Layer

JavaScript functions to analyze user input and fetch relevant career data

Navigation Layer

Login → Home → Career Suggestion → Roadmap display

7. FUNCTIONAL MODULES
7.1 Login Module

Allows users to login using email and password (frontend-based)

Redirects authenticated users to the home page

Includes logout functionality

7.2 Home Page Module

Displays hero section, carousel, career categories, and Tamil Nadu education cards

Acts as the entry point to career analysis

7.3 Career Suggestion Module

Collects user inputs:

Education level

Stream / background

Career interest

Analyzes inputs using JSON data

Displays recommended career and alternatives

7.4 Roadmap Module

Shows step-by-step guidance to achieve the selected career

Helps students understand required actions clearly

8. DATASET DESCRIPTION

The career dataset is stored in a JSON file and includes:

Career name

Eligible education levels

Relevant streams

Career interest category

Step-by-step roadmap

This dataset ensures that:

Each education level has valid career paths

Each stream and interest is covered

Ineligible combinations are handled properly
